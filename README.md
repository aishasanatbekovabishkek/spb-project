
# Job Application Tracker

Курсовой проект по дисциплине
«Конструирование программного обеспечения».

Санкт-Петербургский политехнический университет
Петра Великого, 2026 год.

## 1. Описание проекта

Job Application Tracker — веб-приложение для поиска
вакансий и управления откликами на работу.

При активном поиске работы информация о вакансиях,
собеседованиях, откликах и их статусах часто
оказывается разбросанной по разным сервисам.

Приложение позволяет объединить эту информацию
в одном месте и отслеживать процесс трудоустройства.

## 4. Пользовательские сценарии

- US1: Поиск вакансий по ключевым словам.
- US2: Сохранение интересующих вакансий.
- US3: Создание откликов и изменение статусов.
- US4: Просмотр истории изменения статусов.
- US5: Просмотр статистики откликов.

Дополнительно предусмотрены авторизация,
фильтрация вакансий и напоминания.

## 5. Архитектура

Выбрана клиент-серверная архитектура.

Backend проектируется как модульный монолит,
реализованный на FastAPI.

Frontend взаимодействует с Backend через REST API.

PostgreSQL используется для постоянного хранения,
Redis — для кэширования внешних данных.

## 6. MVP

Минимальная версия должна обеспечивать:

1. Регистрацию и авторизацию.
2. Поиск вакансий через внешний API.
3. Сохранение вакансий.
4. Создание откликов.
5. Изменение статусов.
6. Просмотр истории изменений.

Дополнительные возможности:

- напоминания;
- статистика откликов;
- расширенная фильтрация.

## 7. Разработка и контроль версий

Разработка ведётся с использованием GitHub Issues,
отдельных веток и Pull Requests.

Задачи проходят статусы:

Todo → In Progress → In Review → Done.

Каждый Pull Request связывается
с соответствующей Issue.

## 8. Тестирование

Планируется:

- Unit-тестирование бизнес-логики через Pytest.
- Интеграционное тестирование Backend и PostgreSQL.
- E2E-тестирование пользовательских сценариев
  с помощью Playwright.

Результаты тестирования будут добавлены
после реализации приложения.

## 9. Развёртывание

Планируется контейнеризация компонентов
с помощью Docker Compose.

После реализации будет добавлена инструкция
по запуску приложения одной командой,
включая миграции БД и выполнение тестов.

Реализация MVP, интеграция компонентов,
